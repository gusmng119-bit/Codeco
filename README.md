# CODECO LMS Frontend

Frontend aplikasi **Learning Management System (LMS)** yang dikembangkan selama program magang di PT. CODECO STEAM EDUCATION HUB.

Project ini dibangun menggunakan **React + Vite** dengan arsitektur modern dan menerapkan React Router sebagai routing, Zustand sebagai state management, serta Ant Design sebagai UI Component Library.

---

## Tech Stack

* React 18
* Vite
* React Router
* Ant Design (Antd)
* Zustand
* Axios
* JavaScript / JSX

## Installation

Clone repository

```bash
git clone <repository-url>
```

Masuk ke folder project

```bash
cd codeco-fe
```

Install dependency

```bash
npm install
```

Menjalankan project

```bash
npm run dev
```

Build production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```

## State Management

Project menggunakan **Zustand** untuk mengelola global state seperti:

* Authentication
* User Data
* Session
* Global Configuration
* Shared Data

---

## Routing

Project menggunakan **React Router** dengan konsep:

* Public Route
* Protected Route
* Nested Route
* Layout Route
